// ---- Audio subsystem globals (0x800927D0–0x80092848 cluster) ----
// The audio system uses a triple-buffer scheme.  gAudioFrameCount is incremented
// each audio frame; slot = gAudioFrameCount % 3 selects which of the three
// s16 entries in gAudioBufSizes and which pointer in D_8017F438[] to use.
//
// gAudioOutputCtx: persistent void* handle to the audio output context.
//   Held in $s0 throughout func_8005C0BC; passed as arg0 to numerous audio
//   functions (func_8007EA18, func_8007E9D8, etc.).
// gAudioBufSizes: s16[3] array (stride 2 bytes) at this address.
//   Element [slot] is updated each frame with the computed DMA buffer size
//   (derived from D_801808E2 - gAudioBufBase + 0x28, aligned to 0x10).
// gAudioModeIdx: s32 index into D_8017F370 (audio mode function-pointer table).
//   gAudioFrameCount % 3 is also used here to select the mode entry (× 4 bytes).
// gAudioFrameLock: set to 1 at the start of the per-frame audio DMA setup function
//   (func_8005C688).  Acts as a "frame-in-progress" guard.
// gAudioBufBase: u16 base offset; subtracted from the AI register value and added
//   0x28 to compute the DMA transfer size (with 0x10-byte alignment).
// gAudioStatus: audio state machine.  0 = idle, 3 = DMA in progress, 4 = complete.
//   func_8005C88C is gAudioStatus != 0 && != 4 branch — stores $a0 → gAudioCallback.
// gAudioCfgPtr: cached ptr to field [1] of the module config at D_800927F0;
